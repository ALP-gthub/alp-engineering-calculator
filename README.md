# ALP Engineering Calculator

GitHub Pages üzerinde çalışacak statik 3 faz motor ve kablo hesaplama aracı.

## Dosyalar
- `index.html` — arayüz
- `style.css` — tasarım
- `script.js` — hesaplama motoru

## GitHub Pages
1. GitHub'da yeni bir repository oluşturun.
2. Bu üç dosyayı repository köküne yükleyin.
3. Settings → Pages → Build and deployment → Deploy from a branch.
4. Branch `main`, klasör `/ (root)` seçin.
5. Save.

## Kapsam
Motor akımı, giriş gücü, yaklaşık gerilim düşümü ve aktif hat kaybı hesaplanır. Bu araç ön boyutlandırma/eğitim içindir; nihai kablo seçimi için döşeme şekli, ortam sıcaklığı, gruplanma, akım taşıma kapasitesi, kısa devre dayanımı, koruma koordinasyonu, kalkış akımı, harmonikler, üretici datası ve ilgili standartlar ayrıca kontrol edilmelidir.
