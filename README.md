# ALP Engineering Calculator

A web-based engineering calculation tool developed for preliminary electrical system analysis and engineering education.

## Live Tool

**[Open ALP Engineering Calculator](https://alp-gthub.github.io/alp-engineering-calculator/)**

## Current Module

### 3-Phase Motor & Cable Calculation

The current module provides a practical calculation environment for:

- Motor line current
- Input electrical power
- Voltage drop
- Voltage drop percentage
- Approximate active line losses
- Copper and aluminium conductors
- Cable cross-section selection
- User-defined cable resistance
- Cable reactance
- Temperature correction factor

## Calculation Basis

The tool uses standard electrical engineering relationships for preliminary calculations.

### Three-phase motor current

`I = Pout / (√3 × V × cosφ × η)`

### Voltage drop

`ΔV = √3 × I × L × (R × cosφ + X × sinφ)`

### Voltage drop percentage

`ΔV% = (ΔV / V) × 100`

### Three-phase active line loss

`Ploss ≈ 3 × I² × R`

## Engineering Scope

This application is intended for **preliminary engineering calculations and educational purposes**.

Final cable selection and electrical system design require additional evaluation of project-specific conditions, including:

- Installation method
- Ambient temperature
- Cable grouping
- Current-carrying capacity
- Cable type and insulation
- Short-circuit withstand capability
- Protection device coordination
- Motor starting conditions
- Harmonics
- Manufacturer data
- Applicable standards and project requirements

The results generated by this tool should therefore be verified before being used in an actual installation or engineering design.
